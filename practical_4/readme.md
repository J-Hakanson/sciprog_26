This practical calculates the value of tan(x) by putting the results of tan(x) in a global variable, then finds the area under the curve for tan(x) from 0 to 60 degrees using the trapezoidal rule.

When the program is run, there are a few sentences discussing the results that are printed.

It can be run by executing the following commands in your terminal:

To compile: gcc -Wall -o practical4 practical4.c -lm
	(using -lm to ensure tan function is available)

To run: ./practical4
