This practical defines whether or not a given square is magic. The program reads an input from a text file, reads the size of the matrix from it (first integer), then checks the matrix below to see if it is magic. A magic square is one where every row, column, and main diagonals sum to the same value M. After reading and doing the necessary algebra on all rows, diagonals, and columns it returns a 1 of it's magic and 0 if not. This number then prints whether the square is magic or not.



This code can be run by executing the following commands in your terminal:

gcc -o practical_9 practical_9.c

./practical_9
